# Function
**PC:**
* Use `LumiaExtend_Server_x64_v1.0.0_Release.exe` as the server application to ensure the Lumia WP device functions correctly.

**Lumia WP:**
1. Supports extending the PC screen to the Lumia WP device remotely.
2. Supports remote mouse input.
3. Supports remote keyboard input.

# Requirements & Setup
**On PC:**
1. Installing `IddSampleDriver` is mandatory for proper operation; set it up as the second (2nd) display.
2. Download and run `LumiaExtend_Server_x64_v1.0.0_Release.exe` normally; no configuration is required.

**On Lumia WP:**
1. Download `LumiaExtend_1.0.0_Release.zip`
2. Extract the files, and transfer them to the Lumia WP device.
3. Install `LumiaExtend_1.0.0_arm.cer` followed by `LumiaExtend_1.0.0_arm.appxbundle`.

# Known Issues
Due to hardware limitations on some older Lumia WP devices, the frame rate may not exceed 30 FPS. The default resolution is 720p.
It only works with the second (2nd) display; it will not function with other displays (e.g., the 1st or 3rd).

**If installation on the Lumia WP fails:**
1. Try restarting the device
2. Then install the components found in the "Dependencies" folder (matching your CPU architecture).
3. Afterward, attempt to install the two main files mentioned above again.
